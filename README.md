# CHICC V4
Multi-page luxury fine jewellery concept.

Files:
- index.html
- category.html
- product.html
- styles.css
- script.js
- products.js
- assets/ (all product images stored locally)

There are 32 product concepts across Rings, Earrings, Necklaces and Bracelets.
Every product opens a dedicated product-detail experience using product.html?id=...
Pricing remains private and the enquiry form pre-fills the selected piece.

Upload every file and the full assets folder to the root of the existing GitHub repository.
